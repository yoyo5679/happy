# 구글 플레이 스토어 등록 안내 (해피케어 앱)

해피케어 사이트(https://happycare.pages.dev)를 **TWA(신뢰할 수 있는 웹 활동)** 방식의 안드로이드 앱으로 올립니다.
앱은 사이트를 그대로 보여 주므로, 사이트를 고치면 앱도 바로 바뀝니다(앱 업데이트 불필요).

사이트 쪽 준비(완료): 앱 매니페스트(`public/manifest.webmanifest`), 아이콘, 서비스워커(`public/sw.js`), 오프라인 안내 화면(`public/offline.html`), 개인정보처리방침의 앱 항목.

---

## 1. 구글 플레이 개발자 계정 – 기존 개인 계정 사용 (2026년 생성)

- 이미 있는 **개인 계정**으로 등록합니다(추가 등록비 없음). 나중에 사업자(조직) 계정을 만들면 플레이 콘솔의 '앱 이전'으로 옮길 수 있습니다.
- 2023년 11월 13일 이후 만든 개인 계정이라, **정식 출시 전에 비공개 테스트(테스터 12명 이상 · 14일 연속)**가 필요합니다. → 아래 3-1 참고
- 스토어에는 개발자 이름과 연락 이메일이 공개됩니다.

## 2. 앱 파일 – 완료 (Bubblewrap으로 직접 빌드)

- 구글 공식 도구 Bubblewrap으로 `android/` 폴더에 앱 프로젝트를 만들고 빌드했습니다. (PWABuilder 서비스는 당시 503 장애)
- 패키지 이름 `com.happycaremall.app` · 앱 이름 해피케어복지용구 · 아이콘 이름 해피케어 · 시작 주소 `/?src=playstore` · 위치 권한 위임 켬 · 최소 안드로이드 7.0(API 24) · 대상 API 36
- 결과물(저장소에는 올리지 않음, 대표님께 zip으로 전달): `happycare-1.0.0.aab`(플레이 콘솔 업로드용), `happycare-1.0.0-test.apk`(휴대폰 직접 설치 테스트용), `happycare-upload.keystore` + `서명키-정보-꼭보관.txt`
- 사이트의 `public/.well-known/assetlinks.json`에 업로드 키 지문을 넣어 배포했습니다.

### 다시 빌드할 때 (버전 올리기)
1. `android/twa-manifest.json`과 `android/app/build.gradle`의 `versionCode`(+1)·`versionName` 수정
2. `android/`에 `happycare-upload.keystore`를 두고 `local.properties`에 `sdk.dir=안드로이드SDK경로`
3. `./gradlew bundleRelease` → `jarsigner -keystore happycare-upload.keystore ... app-release.aab happycare`
   (또는 `npx @bubblewrap/cli build` — 같은 키 사용)

### 앱 올리기
1. **테스트 → 내부 테스트**에 `.aab` 업로드 → 본인 휴대폰에서 설치해 확인
2. **설정 → 앱 무결성 → 앱 서명**에 나오는 **"앱 서명 키 인증서 SHA-256 지문"**을 보내 주세요.
   플레이가 앱을 다시 서명하므로, 이 지문도 `assetlinks.json`에 추가해야 주소창이 안 보입니다.
3. 아래 3-1 비공개 테스트(12명·14일) → **프로덕션** 출시 신청 → 심사(보통 며칠)

## 3-1. 비공개 테스트 (개인 계정 필수)

1. **테스트 → 비공개 테스트 → 트랙 만들기** → 같은 `.aab`(또는 내부 테스트 버전)를 올림
2. **테스터 → 이메일 목록 만들기**에 테스터 **12명 이상**의 구글(Gmail) 계정 등록. 여유 있게 **15명 정도** 권장
3. 국가/지역: 대한민국 → **검토를 위해 변경사항 보내기**(비공개 테스트도 짧은 심사가 있음)
4. 승인되면 나오는 **테스트 참여 링크**를 테스터에게 보내기 (아래 문구 사용)
5. 테스터가 '테스터 되기' → 플레이 스토어에서 설치 → **14일 동안 지우지 않기**
6. 14일이 지나면 대시보드에서 **프로덕션 액세스 신청** → 질문(테스트 인원·받은 의견·출시 준비 이유)에 답하고 신청

> 14일은 '12명 이상이 동시에 참여 중인 기간'으로 셉니다. 중간에 누가 빠져 12명 아래로 내려가면 다시 늘 수 있으니 처음부터 15명 정도로 시작하세요.
> 테스트 기간에 앱 내용에 대한 의견을 한두 개 받아 두면 프로덕션 신청 질문에 답하기 좋습니다.

**테스터에게 보낼 문구 (예시)**

```
[해피케어 앱 테스트 부탁드려요]
해피케어복지용구 안드로이드 앱 출시 전 테스트에 참여해 주세요. (2주, 무료)

1) 아래 링크를 휴대폰(안드로이드)에서 열고 '테스터 되기'를 눌러 주세요
   (링크)
2) 플레이 스토어에서 '해피케어'를 설치해 주세요
3) 2주 동안 지우지 말고, 가끔 열어서 둘러봐 주세요
   불편한 점이나 의견이 있으면 알려 주시면 큰 도움이 됩니다!
※ 플레이 스토어에 로그인된 구글(Gmail) 계정 주소를 알려 주셔야 초대할 수 있어요.
```


## 4. 출시 후

- 사이트 수정은 평소처럼 배포만 하면 앱에도 바로 반영됩니다.
- 앱 이름·아이콘·주소를 바꿀 때만 PWABuilder로 새 버전(버전 코드 +1)을 만들어 올립니다. **같은 서명 키**로 만들어야 합니다.
- 앱으로 들어온 방문은 `src=playstore`로 구분됩니다.
