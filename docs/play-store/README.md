# 구글 플레이 스토어 등록 안내 (해피케어 앱)

해피케어 사이트(https://happycare.pages.dev)를 **TWA(신뢰할 수 있는 웹 활동)** 방식의 안드로이드 앱으로 올립니다.
앱은 사이트를 그대로 보여 주므로, 사이트를 고치면 앱도 바로 바뀝니다(앱 업데이트 불필요).

사이트 쪽 준비(완료): 앱 매니페스트(`public/manifest.webmanifest`), 아이콘, 서비스워커(`public/sw.js`), 오프라인 안내 화면(`public/offline.html`), 개인정보처리방침의 앱 항목.

---

## 1. 구글 플레이 개발자 계정 (직접)

- https://play.google.com/console 에서 가입, 등록비 25달러(1회).
- **조직(사업자) 계정을 권장합니다.** 사업자등록증이 있으면 조직 계정으로 가입하세요. D-U-N-S 번호가 필요합니다(무료, 발급에 며칠~수 주).
- **개인 계정**으로 가입하면, 출시 전에 **테스터 12명 이상이 14일 연속 비공개 테스트**를 해야 정식 출시할 수 있습니다(2023년 11월 이후 만든 개인 계정 기준). 조직 계정은 이 조건이 없습니다.
- 개발자 연락처(이메일·전화)와 주소는 스토어에 공개됩니다.

## 2. 앱 파일 만들기 – PWABuilder (직접, 10분)

1. https://www.pwabuilder.com 접속 → 주소에 `https://happycare.pages.dev` 입력 → **Start**.
2. **Package For Stores → Android → Generate Package**.
3. 옵션(Options)에서 아래처럼 입력:

| 항목 | 값 |
|---|---|
| Package ID | `com.happycaremall.app` (한 번 정하면 바꿀 수 없음) |
| App name | 해피케어복지용구 |
| Short name (Launcher name) | 해피케어 |
| App version / version code | 1.0.0 / 1 |
| Host | happycare.pages.dev |
| Start URL | `/?src=playstore` |
| Theme color / Background color | `#068291` / `#FFFFFF` |
| Display mode | Standalone |
| Notifications | 끔 |
| Location delegation | **켬** (기관 찾기 '내 위치' 사용) |
| Google Play billing | 끔 |
| Signing key | **Create new** (새로 만들기) – 이름·조직: 해피케어, 국가: KR |

4. **Download** → zip 안에 다음이 들어 있습니다.
   - `*.aab` : 플레이 콘솔에 올리는 파일
   - `signing.keystore` + `signing-key-info.txt` : **앱 서명 키. 잃어버리면 앱을 다시 올릴 수 없으니 안전한 곳 두 군데 이상에 보관** (채팅·저장소에 올리지 마세요)
   - `assetlinks.json` : 사이트와 앱을 잇는 인증 파일

5. **`assetlinks.json` 파일 내용만** 보내 주세요. (공개해도 되는 정보: 패키지 이름 + 인증서 지문)
   → 사이트의 `public/.well-known/assetlinks.json`에 넣어 배포합니다. 이게 있어야 앱 위쪽에 주소창이 안 보입니다.

### 데이터 보안 답안
| 질문 | 답 |
|---|---|
| 사용자 데이터를 수집하거나 공유하나요? | **예** (위치) |
| 전송 중 암호화 | 예 (HTTPS) |
| 데이터 삭제 요청 방법 | 저장하는 개인 데이터가 없음 (문의: ifogme@naver.com) |
| 수집 항목 | **위치 – 정밀한 위치, 대략적인 위치** |
| 수집 목적 | 앱 기능 (가까운 장기요양기관 찾기) |
| 일시적 처리(ephemeral) | **예** – 검색에만 쓰고 저장하지 않음 |
| 필수/선택 | **선택** (위치 대신 동네 이름으로 검색 가능) |
| 제3자 공유 | 아니요 (지도 검색 업체는 서비스 제공업체로 '공유'에 해당하지 않음) |
| 그 밖의 항목(이름·연락처·결제·건강·사진·기기 ID 등) | 수집 안 함 |

> 정책 답안은 운영 방식이 바뀌면(예: 회원가입·문의 양식 추가) 같이 고쳐야 합니다.

### 앱 올리기
1. **테스트 → 내부 테스트**에 `.aab` 업로드 → 본인 휴대폰에서 설치해 확인
2. **설정 → 앱 무결성 → 앱 서명**에 나오는 **"앱 서명 키 인증서 SHA-256 지문"**을 보내 주세요.
   플레이가 앱을 다시 서명하므로, 이 지문도 `assetlinks.json`에 추가해야 주소창이 안 보입니다.
3. (개인 계정이면) 비공개 테스트 12명·14일 → **프로덕션** 출시 신청 → 심사(보통 수일)

## 4. 출시 후

- 사이트 수정은 평소처럼 배포만 하면 앱에도 바로 반영됩니다.
- 앱 이름·아이콘·주소를 바꿀 때만 PWABuilder로 새 버전(버전 코드 +1)을 만들어 올립니다. **같은 서명 키**로 만들어야 합니다.
- 앱으로 들어온 방문은 `src=playstore`로 구분됩니다.
